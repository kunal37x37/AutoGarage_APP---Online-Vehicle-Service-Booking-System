# 🚗 AutoGarage - Online Vehicle Service Booking System

> An Android application that connects vehicle owners with local garages for seamless service booking and management.

---

## 📱 About The Project

**AutoGarage** is a comprehensive Android application designed to simplify vehicle service booking. Users can discover local garages, book services, schedule appointments, make secure payments, and communicate directly with garage owners—all from a single platform.

Garage owners can manage their business efficiently by accepting/rejecting bookings, updating service availability, and communicating with customers in real-time.

---

## ✨ Key Features

### For Users
- 🔐 **Registration & Login** - Secure account creation and authentication
- 🔍 **Garage Discovery** - Find local garages with detailed information
- 📋 **Service Booking** - Select services, choose date/time, and book instantly
- 💳 **Multiple Payment Options** - Secure and flexible payment methods
- 💬 **Real-time Messaging** - Direct communication with garage owners
- 📊 **Booking Status** - Track service request status in real-time
- 👤 **Profile Management** - Update personal information and settings

### For Garage Owners
- 🏪 **Garage Registration** - Register business with complete details
- 📅 **Booking Management** - Accept or reject service requests
- 🔄 **Availability Updates** - Manage service status and working hours
- 📱 **Customer Communication** - Direct chat with customers
